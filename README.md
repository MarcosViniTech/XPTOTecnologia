# XPTO Tecnologia

**Projeto Acadêmico | 4º Semestre de Ciência da Computação | UNINOVE**

Projeto acadêmico desenvolvido em equipe durante o 4º semestre de Ciência da Computação da UNINOVE.

Este repositório tem como objetivo documentar minha participação no projeto, destacando as atividades de organização dos arquivos, estruturação do repositório no GitHub e produção audiovisual da apresentação final.

## 📂 Organização e estruturação do GitHub

Fiquei responsável pela criação, estruturação e organização do repositório principal do projeto no GitHub, reunindo os arquivos, pastas e materiais desenvolvidos pelos integrantes da equipe.

Entre as atividades realizadas:

- Criação e estruturação do repositório principal.
- Organização das pastas, arquivos e entregáveis do projeto.
- Centralização dos materiais desenvolvidos pela equipe.
- Registro e acompanhamento das alterações por meio de commits.

🔗 **Repositório completo:** [XPTO_Projeto_Uninove](https://github.com/MarcosViniTech/XPTO_Projeto_Uninove)

O repositório reúne os materiais e entregas do projeto acadêmico, permitindo consultar e acompanhar o trabalho desenvolvido durante o semestre.

## 🎬 Edição do vídeo de apresentação

Fiquei responsável pela edição e montagem do vídeo de apresentação final do projeto, utilizando como base a gravação de áudio realizada pelo integrante Marco.

As atividades envolveram:

- Criação de imagens para ilustrar e demonstrar o projeto.
- Gravação de vídeos das telas e funcionalidades desenvolvidas.
- Organização das imagens, gravações e demais elementos visuais.
- Montagem e sincronização dos vídeos com a narração.
- Edição e finalização do material utilizando CapCut.

O objetivo foi reunir os diferentes elementos em uma apresentação visual organizada, demonstrando o projeto e documentando da melhor forma possível o trabalho realizado pela equipe.
